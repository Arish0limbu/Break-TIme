# Security Policy

## Supported versions

Security updates are applied to the default branch. No release support schedule is currently published.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's Security Advisories page for this repository, if private reporting is enabled. Do not include credentials, tokens, or personal data in a public issue. If private reporting is unavailable, open a minimal issue asking the maintainers to enable a private channel without disclosing exploit details.

This helper runs Git only when invoked, previews by default, and pushes only when the explicit --push option is supplied. Never place secrets in command-line arguments or commit messages.
